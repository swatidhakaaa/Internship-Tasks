Project Report: 2BHK Residential Building Design

Domain: Architectural & Civil Drafting using AutoCAD

1. Executive Summary

This project presents a comprehensive 2D architectural blueprint and structural sectional plan for a single-storey 2BHK residential building. Developed adhering to standard drafting guidelines, local municipal bylaws, and architectural standards, this project demonstrates accurate spatial planning, precise layer organization, line-weight management, and structural annotation techniques in AutoCAD.

2. Design Specifications & Building Parameters

Parameter Specification
Plot Dimensions 30 ft × 40 ft (1,200 sq. ft. total area)
Built-up Area Approx. 850 sq. ft.
Structure Type Load-bearing / Reinforced Concrete Frame
Wall Thickness Exterior: 9 inches (230 mm) | Interior: 4.5 inches (115 mm)
Ceiling Height 10 ft (3,048 mm) from finished floor level (FFL)
Plinth Height 1 ft 6 inches (450 mm) above ground level (GL)

3. Drafting Methodology & AutoCAD Workflow

  1. Unit & Grid Configuration: Set unit type to Architectural with precision set to 0'-0". Established plot limits at 50',50' and turned on Object Snap (F3) and Ortho Mode (F8).
  2. Layer Management: Created distinct functional layers to ensure CAD standard compliance:
    • 0_WALLS (Cyan, Lineweight 0.35 mm)
    • 0_DOORS_WINDOWS (Yellow, Lineweight 0.25 mm)
    • 0_DIMENSIONS (Red, Lineweight 0.15 mm)
    • 0_HATCH (Dark Gray, Lineweight 0.09 mm)
  3. Layout Drafting: Formed boundary lines using OFFSET and TRIM. Inserted block symbols for doors, windows, and sanitary fixtures. Applied ANSI31 hatch patterns for wall cutouts in section views.
  4. Plotting & Export: Configured standard layout viewports in Paper Space at 1:50 scale and exported to high-resolution PDF for client submittal.
